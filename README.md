# Daily Spend Tracker

This is a simple static app (HTML/CSS/JS). To preview it locally:

```bash
python -m http.server 8000
```

Then open <http://127.0.0.1:8000/index.html> in your browser.

If you prefer, you can also open `index.html` directly in your browser, but some browsers block local storage on `file://` URLs, so running a local server is recommended.
